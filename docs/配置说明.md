# 配置在哪儿改

| 范围 | 文件                                       | 用途                                                                                         |
| ---- | ------------------------------------------ | -------------------------------------------------------------------------------------------- |
| 前端 | `package.json`、`pnpm-lock.yaml`           | 前端命令、依赖和锁定版本；使用 pnpm。                                                        |
| 前端 | `vite.config.js`                           | 开发端口、接口代理、构建和预览。                                                             |
| 前端 | `tsconfig.json`                            | 检查 JS + JSDoc 的类型，不负责打包。                                                         |
| 前端 | `eslint.config.js`、`prettier.config.js`   | 代码检查和格式化。                                                                           |
| 后端 | `pyproject.toml`、`uv.lock`                | Python 依赖、打包和 Ruff；使用 uv。                                                          |
| 后端 | `langgraph.json`                           | `graphs` 注册图，`http.app` 加载 FastAPI，`http.cors` 配置跨域，`env` 指定环境文件。         |
| 后端 | `.env`、`.env.example`                     | Agent Server、业务数据库、LangSmith 的地址与凭据；`.env` 不进 Git。Vite 使用后端地址做代理。 |
| 后端 | `Makefile`                                 | `make dev` 启动开发 Agent Server；也可以直接执行里面的命令。                                 |
| 部署 | `deploy/compose.yaml`                      | 应用服务及 Agent Server 自用的 PostgreSQL、Redis。                                           |
| 部署 | `deploy/database.compose.yaml`             | 独立业务 PostgreSQL。                                                                        |
| 部署 | `deploy/*.Dockerfile`、`deploy/nginx.conf` | 前后端镜像和生产代理。                                                                       |
| 共用 | `.gitignore`、`.dockerignore`              | 排除本机依赖、临时产物和密钥。                                                               |

`package.json` 和 `langgraph.json` 使用严格 JSON，不添加注释字段。`tsconfig.json` 支持注释。

修改 `.env` 后重启后端；修改 Agent Server 的跨域或入口配置时，同时核对 `langgraph.json` 和 `deploy/Agent.Dockerfile`。

已执行的 SQL 迁移有校验和，不能为了加注释修改旧文件；表结构变化应新增迁移。

# 配置在哪儿改

| 范围 | 文件                                       | 用途                                                                                         |
| ---- | ------------------------------------------ | -------------------------------------------------------------------------------------------- |
| 前端 | `package.json`、`pnpm-lock.yaml`           | 前端命令、依赖和锁定版本；使用 pnpm。                                                        |
| 前端 | `vite.config.js`                           | 开发端口、接口代理、构建和预览。                                                             |
| 前端 | `tsconfig.json`                            | 检查 JS + JSDoc 的类型，不负责打包。                                                         |
| 前端 | `eslint.config.js`、`prettier.config.js`   | 代码检查和格式化。                                                                           |
| 后端 | `pyproject.toml`、`uv.lock`                | Python 依赖、打包和 Ruff；使用 uv。                                                          |
| 后端 | `langgraph.json`                           | `graphs` 注册图，`http.app` 加载 FastAPI，`http.cors` 配置跨域，`env` 指定环境文件。         |
| 后端 | `.env`、`.env.example`                     | Agent Server、业务数据库、LangSmith 的地址与凭据；`.env` 不进 Git。Vite 使用后端地址做代理。 |
| 后端 | `Makefile`                                 | `make dev` 启动开发 Agent Server；也可以直接执行里面的命令。                                 |
| 部署 | `deploy/compose.yaml`                      | 应用服务及 Agent Server 自用的 PostgreSQL、Redis。                                           |
| 部署 | `deploy/database.compose.yaml`             | 独立业务 PostgreSQL。                                                                        |
| 部署 | `deploy/*.Dockerfile`、`deploy/nginx.conf` | 前后端镜像和生产代理。                                                                       |
| 共用 | `.gitignore`、`.dockerignore`              | 排除本机依赖、临时产物和密钥。                                                               |

`package.json` 和 `langgraph.json` 使用严格 JSON，不添加注释字段。`tsconfig.json` 支持注释。

修改 `.env` 后重启后端；修改 Agent Server 的跨域或入口配置时，同时核对 `langgraph.json` 和 `deploy/Agent.Dockerfile`。

同一本地数据库端口只运行一条 SSH 隧道，并启用保活（参考 `.env.example`）。数据库建连接超时为 15 秒；单条 SQL 超时 15 秒、锁等待超时 10 秒。

已执行的 SQL 迁移有校验和，不能为了加注释修改旧文件；表结构变化应新增迁移。

环境配置在 `core/config.py` 使用 `pydantic-settings.BaseSettings` 校验；运行时读取进程环境，`.env` 由 `langgraph.json` 或 `uv --env-file .env` 加载。独立工具可显式调用 `Settings(_env_file=".env")`。图输入、状态、输出和 Context 使用 Pydantic 模型，字段错误在调用模型前报出。

模型档案详情 →「配置接入」，按官方服务和用途选择，系统自动显示任务及对应参数。运行工作室统一上传素材、运行、预览和下载；分析保留多轮历史，生成只使用本轮提示词和素材。成功结果可确认录入实验。

| 服务                            | 当前接入能力                                                                    | 官方说明                                                                                                                                                                   |
| ------------------------------- | ------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Qwen VL、OpenAI 兼容、Anthropic | 文本 / 图片分析；Qwen VL 可直接分析视频，需启用视频输入。Anthropic 当前只接图片 | [Qwen 视觉](https://help.aliyun.com/zh/model-studio/vision)                                                                                                                |
| GPT Image                       | 文生图、多图编辑，官方 Images API                                               | [OpenAI](https://developers.openai.com/api/docs/guides/image-generation)                                                                                                   |
| Qwen Image                      | 文生图、最多 3 图编辑；具体能力取决于模型版本                                   | [阿里](https://help.aliyun.com/zh/model-studio/qwen-image-edit-api)                                                                                                        |
| Seedance、Wan 3.0               | 文生视频、首帧 / 首尾帧生视频，提交后自动轮询                                   | [字节](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)、[万相](https://help.aliyun.com/en/model-studio/wan3-video-generation-api-reference) |
| Krea 2                          | Medium / Large 文生图、单图生成，输出 1K                                        | [Krea](https://www.krea.ai/docs/developers/krea-2/overview)                                                                                                                |
| MOSS Image                      | 文生图，不接参考图                                                              | [MOSI](https://platform.moss.cn/docs/reference/images-generations)                                                                                                         |
| MiniMax H3-Image                | 文生图、多图编辑                                                                | [MiniMax](https://github.com/MiniMax-AI/MiniMax-H3-Image)                                                                                                                  |

填写账号已开通的模型 ID；Seedance 也接受 Endpoint ID。阿里地址和密钥须同地域；原有 `compatible-mode/v1` 地址可保留，原生生成适配器会转换路径并保留业务空间域名。已知官方万相、Qwen Image、GPT Image 旧配置会自动识别到生成协议。

国内百炼、方舟等已知官方端点使用直连，海外及自定义服务继承环境代理；模型连接阶段上限 15 秒，读取使用档案中的等待超时。百炼支持开关的 Qwen 混合思考模型默认关闭深度思考，可在接入配置中选择开启或模型默认。Qwen 使用流式传输，完成后展示结果；开启深度思考时应相应增加等待超时。[阿里思考模式说明](https://help.aliyun.com/en/model-studio/deep-thinking)

Seedance、万相的视频参考需要公网 URL / 平台素材，本系统当前接入本地图片作为首尾帧，不把本地视频地址伪装成公网链接。生成参数只发送此协议支持的部分，不会把 Cosmos 采样步数传给其他视频接口。无需新增依赖。

`PRISM_MODEL_ENCRYPTION_KEY` 用于加密数据库中的模型 API Key，必须配置有效的 Fernet 密钥；部署时保持相同值并备份。研究 JSON 备份不含接入配置、密钥、媒体或聊天历史，完整恢复须备份 PostgreSQL 和加密根密钥。工具尚未接入。

Cosmos 填写完整调用地址 `https://ai.api.nvidia.com/v1/cosmos/nvidia/cosmos3-nano`；模型标识可填 `nvidia/cosmos3-nano`。支持文生图、文生视频、单图生视频和单视频编辑，使用本轮提示词及附件；参数在接入配置中设置，聊天里可切换任务。建议先用 480 档、25 帧，超时设为 600 秒。该适配器使用已有 httpx，未新增依赖。[官方接口与模式说明](https://build.nvidia.com/nvidia/cosmos3-nano/modelcard)。

上传原始媒体及生成结果保存在 PostgreSQL 的 `media_assets` 表，运行记录 `input_media` 和图输出 `media` 只保存引用。图片上传上限 10 MB、视频 32 MB，每轮最多 6 个文件，上下文媒体总量上限 64 MB；支持 PNG/JPEG/WebP/GIF、MP4/WebM。生成结果可预览和下载，视频支持 Range 请求。重启后端会自动执行 `004_multimodal_media.sql`。

重启后端还会执行 `005_generation_jobs.sql`，在 `generation_jobs` 保存异步厂商任务号。计费提交不自动重试；超时或中断可能仍在厂商执行，请查询原任务。生成建议等待 900 秒。临时结果链接会校验公网地址并转存到数据库，下载不携带 API Key。
